# HealthSync-OS
HealthSync OS directly embodies "Agentic AI for Good" by advancing AI from a passive text-based assistant into an autonomous, action-oriented platform that solves critical healthcare bottlenecks. In doing so, HealthSync OS advances UN Sustainable Development Goals 3 (Good Health and Well-Being) and 12 (Responsible Consumption and Production).

## Running the frontend

The frontend is plain HTML, CSS and JavaScript, so there is nothing to install or build. From the project root:

```
python -m http.server 5173 --directory frontend
```

Then open http://localhost:5173 in your browser.

The dashboard uses sample data from `frontend/data.js`. Click **Approve and submit** to step through the workflow, and **Reset demo** to start over.
